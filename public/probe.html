How to read this

  • PRESENT plus a successful registerTool means this browser can host Understudy tools.
  • ABSENT means turn on chrome://flags/#enable-webmcp-testing, or open this file in ChatGPT's in-app browser. Humans can still use the app with no agent.
  • This probe registers only on document.modelContext. It does not call the removed navigator.modelContext getter. That getter is reported as a side reading.
